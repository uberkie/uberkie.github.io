API Reference¶

This page documents the public API that callers are expected to use. It avoids dumping adapter internals and derived endpoint properties into the main reference; the full source remains linked through [source] where useful.

Import Path Overview¶

Most code should import from network_lang first:

from network_lang import (
    build_operation,
    network,
    parse_text,
    target_device,
    validate_operation,
)

Adapter-specific planning and execution helpers live under network_lang.adapters:

from network_lang.adapters import (
    RouterOSExecutor,
    RouterOSRestTransport,
    plan_routeros_operation,
    plan_airos_operation,
)

Core Entry Points¶

API

Use

network_lang.network

Fluent operation builder, for example network.interfaces.get(...).

network_lang.build_operation()

Build an operation from a dotted operation name.

network_lang.parse_text()

Parse one or more text operations.

network_lang.parse_file()

Parse operations from a .uns file.

network_lang.validate_operation()

Validate a single operation.

network_lang.validate_operations()

Validate a list of operations.

network_lang.target_device()

Resolve inventory and create an adapter-backed target.
